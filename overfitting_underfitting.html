Ways to fix underfitting
Increase model capacity
Use a higher-degree polynomial, a deeper network, or more trees. Give the model room to learn.
Add better features
Create interaction terms or bring in domain knowledge the model currently can't see.
Ease off regularization
If λ is too high the model is over-penalized and can't fit even the real pattern. Lower it gradually.
Train for more epochs
In neural networks, the model may simply need more passes through the data before it converges.
Ways to fix overfitting
Collect more data
The most dependable fix. A larger dataset is much harder to memorize, so the model is forced to generalize.
Add a regularization penalty
Ridge (L2) shrinks all coefficients toward zero. Lasso (L1) goes further and zeros out the least useful ones entirely.
Simplify the model
Fewer layers, a lower polynomial degree, shallower trees. Match the model's capacity to the problem's real complexity.
Stop at the right time
Watch the validation error during training. Once it starts climbing, stop. Training error may still be falling, but validation error is what matters.
Use dropout (neural nets)
Randomly switch off neurons during training so the network can't rely on any single path, so it builds more robust representations.
Cross-validate your choices
k-fold cross-validation gives a reliable read on how well the model generalizes, without ever touching the test set.
